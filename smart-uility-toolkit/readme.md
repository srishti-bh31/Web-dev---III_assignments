# Smart Utility Toolkit

A Node.js based backend lab project that demonstrates the fundamentals of backend development using Node.js core modules.

This project contains multiple mini utilities including a command-line calculator, custom module, HTTP server, file manager, and random dice generator.

---

## 📌 Project Overview

The Smart Utility Toolkit is developed as part of the Web Dev III (Node.js & Express Backend) lab assignment.

The main purpose of this project is to understand how Node.js works outside the browser and how its built-in modules can be used to perform common backend tasks without external packages or frameworks.

---

## 🎯 Learning Objectives

This project demonstrates:

- Command-line input using `process.argv`
- Custom module creation using `module.exports`
- Module importing using `require()`
- HTTP server creation using the `http` module
- Basic URL routing
- File handling using the `fs` module
- Create, Read, Update and Delete operations
- Random number generation using the `crypto` module
- Error handling
- Console logging and execution analysis
- Modular and reusable JavaScript code

---

## 🛠️ Technology Stack

- Node.js
- JavaScript (ES6)
- Node.js Core Modules
- Terminal / Command Prompt

### Node.js Core Modules Used

- `process`
- `http`
- `fs`
- `crypto`

No external npm packages are required.
